# Requirements

## Functional Requirements

- Staff can start a catalog update.
- Staff can check update status and results.
- The system supports new, updated, and withdrawn products.
- The system prevents duplicate products when updates are replayed.
- Older information must not overwrite newer information.
- Incomplete updates can resume after application restarts.
- A partially completed update must not be reported as complete.

## Out of Scope

- Authentication and authorization
- Order management
- Payment processing
- Live supplier integration
- Production deployment
